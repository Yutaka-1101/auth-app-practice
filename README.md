# auth-app-practice

## 概要

COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。
Laravel Fortifyを用いて、ユーザー認証機能(登録・ログイン・ログアウト) とダッシュボード画面を実装したアプリケーションを作成しました。

## 使用技術

- PHP 8.x
- Laravel 10.x
- Laravel Fortify（認証）
- MySQL

## 学んだこと

- Fortifyが認証処理を担当する仕組み
- authミドルウェアによるアクセス制御
- ログイン後のリダイレクト設定の流れ

## 動作確認

- /registar にアクセスし、ユーザー登録ができることを確認
- 登録後、自動で /dashboard に遷移することを確認
- /login からログインできることを確認
- 未ログイン状態で /dashboard にアクセスすると /login にリダイレクトさせることを確認
- ダッシュボードにユーザー名・メールアドレスが表示されることを確認
- ログアウト後、トップページに戻ることを確認
